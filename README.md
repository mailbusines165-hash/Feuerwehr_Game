# Feuerwehr Einsatzleiter – 3D-Webgame-Prototyp

## Start lokal
1. Node.js installieren.
2. Im Projektordner `npm install`
3. `npm run dev`
4. Die angezeigte localhost-Adresse im Browser öffnen.

## GitHub Pages
Für eine spätere Veröffentlichung kann das Projekt als Vite-App gebaut und über GitHub Actions auf GitHub Pages veröffentlicht werden.

## Nächste Ausbaustufen
- echte 3D-Fahrzeuge und Feuerwehrwache als GLB/GLTF-Modelle
- Straßen-/Navmesh-System, damit Fahrzeuge nur auf befahrbaren Flächen fahren
- Fahrzeugbesatzungen und animierte Personen
- Einsatzsimulation mit Brand, Rauch, Verletzten und Ausbreitung
- Hydranten, Schlauchphysik und Wasserversorgung
- Fahrzeuggeräte/Equipment
- Drehleiter-Animation und Personenrettung
- Einsatzgong und professionelle Sprachmeldungen
- Multiplayer/Backend und Spielstände
